# AgendaTech – Sistema de Gestión de Citas

## 1. Nombre del proyecto

**AgendaTech – Sistema de Gestión de Citas**

## 2. Descripción del proyecto

AgendaTech es una aplicación web desarrollada para facilitar la administración y organización de citas. Su propósito es permitir registrar, consultar, actualizar y eliminar citas mediante una interfaz sencilla, moderna y organizada.

El proyecto fue desarrollado con apoyo de herramientas de inteligencia artificial, principalmente ChatGPT, que se utilizó para planificar el desarrollo, generar código, mejorar el diseño visual y apoyar la corrección de errores.

## 3. Tecnologías utilizadas

- **HTML5:** estructura y organización de la aplicación.
- **CSS3:** diseño visual, colores, distribución y adaptación a diferentes pantallas.
- **JavaScript:** lógica y funcionalidades de la aplicación.
- **localStorage:** almacenamiento local de las citas en el navegador (si está implementado en la versión final).
- **Visual Studio Code:** editor utilizado para desarrollar el proyecto.
- **ChatGPT:** herramienta de inteligencia artificial utilizada como apoyo durante el desarrollo.

## 5. Instrucciones para ejecutar el proyecto

1. Descargar o clonar el repositorio de GitHub.
2. Descomprimir la carpeta del proyecto, si corresponde.
3. Abrir la carpeta AgendaTech en Visual Studio Code.
4. Verificar que los archivos HTML, CSS y JavaScript estén en sus respectivas carpetas.
5. Abrir el archivo `index.html` en un navegador web.
6. También se puede utilizar la extensión Live Server de Visual Studio Code.
7. Una vez abierta la aplicación, utilizar sus opciones para administrar las citas.

No se necesita instalar un servidor backend si la versión final utiliza únicamente HTML, CSS, JavaScript y almacenamiento local.

## 7. Prompts utilizados durante el desarrollo

Se utilizó inteligencia artificial como herramienta de apoyo para desarrollar y mejorar progresivamente el proyecto.

Cada prompt tuvo un propósito específico dentro del proceso.

### Prompt 01 – Planificación del proyecto

**Objetivo:** establecer la idea inicial de AgendaTech, definir sus características principales, los requisitos y las tecnologías que se utilizarían.

### Prompt 02 – Creación de la estructura HTML

**Objetivo:** generar la estructura inicial de la aplicación, incluyendo el menú lateral, el panel de administración, los formularios y la tabla de citas.

### Prompt 03 – Diseño visual con CSS

**Objetivo:** crear los estilos visuales de AgendaTech mediante una interfaz oscura y tecnológica, organizada y fácil de utilizar.

### Prompt 03.1 – Mejoramiento del diseño visual

**Objetivo:** perfeccionar la primera propuesta de diseño, mejorar los colores, la distribución de los elementos, los formularios y la adaptación a diferentes tamaños de pantalla.

### Prompt 04 – Implementación de funcionalidades CRUD

**Objetivo:** desarrollar mediante JavaScript las operaciones para crear, consultar, actualizar y eliminar citas, además de incorporar búsqueda, filtros, validaciones y almacenamiento local, según los requisitos implementados.

### Prompts de corrección

**Objetivo:** identificar problemas encontrados durante las pruebas, solicitar correcciones a la inteligencia artificial y mejorar el código sin perder las funcionalidades existentes.

Los prompts completos y sus explicaciones individuales se encuentran en el archivo `PROMPTS.md`.

## 8. Uso responsable de inteligencia artificial

ChatGPT fue utilizado como herramienta de apoyo durante el desarrollo del proyecto. Sin embargo, el código generado fue revisado, ejecutado y comprobado para identificar errores y realizar las modificaciones necesarias.

El propósito fue comprender la función de cada archivo y de las principales instrucciones del código, evitando limitar el trabajo a copiar y pegar las respuestas de la inteligencia artificial.
